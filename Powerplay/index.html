ⓘ Information & Tips

How do I find a system's Control Score / %?
Go to inara.cz, search the system, and you'll see its Powerplay state and progress, e.g. Exploited 25.6%. Either type the Control Score directly if you know it, or use the “calculate from system state” option and enter the state + that percentage instead.
What's the difference between CS and merits?
Merits are what you personally earn for a delivery. Control Points (CS) are what actually move a system's score, and are worth a quarter of the merit value: CS per delivery = Merits ÷ 4. All figures on this page are post-4× multiplier.
How does Import Info work?
Click “↑ Import Info” in the Current Inventory section and select your ShipLocker.json file to auto-fill your Data and on-foot Power Goods counts, instead of typing them in by hand.

You'll find it in your Elite Dangerous saved games folder, alongside your Journal log files:
C:\Users\<YourUsername>\Saved Games\Frontier Developments\Elite Dangerous\

The game rewrites this file live, so grab the latest copy while docked or after visiting your ship locker/backpack. Only your own items (not a crewmate's) are imported — anything picked up by another CMDR riding in your ship is skipped automatically so it doesn't skew your totals.
⚠ Only import if everything in the file is meant for this system. ShipLocker.json doesn't record which star system your Data or Goods came from — there's no way for this page (or any tool) to tell. If you're working multiple Powerplay fronts at once and haven't handed in or dropped off items from an earlier system, importing will count that leftover stock toward this one too and inflate your totals.

What does the Share Link button do?
Copies a URL that pre-fills this page with the system, score/state, mode, and CMDR split — handy for sending to squadmates. It deliberately leaves out inventory, so opening someone else's link won't overwrite your own saved counts.
Does this page save my data?
Yes, locally in your browser only (nothing is sent anywhere else). That's why the “Clear” button exists at the top — use it if you don't want the system name or inventory remembered for next time.

📚 How to Use This Site

1

Set your target

Type the System Name and either paste in its Control Score directly, or use “calculate from system state” and pick the state + progress % shown on inara.cz.

2

(Optional) Pick Reinforce or Undermine

Only toggle one of these if you're pushing the score up or tearing it down rather than a neutral acquisition — it applies the ±15% merit modifier everywhere on the page.

3

Add your inventory

Type your Data/Goods counts in manually, or click “↑ Import Info” and select your ShipLocker.json file to fill them in automatically. Only import if everything in it is meant for this system — see the Info & Tips FAQ for why.

4

Split between CMDRs (if working as a squad)

Set how many CMDRs are contributing and the results grid will show what's needed per person instead of the total.

5

Read your results

The four cards show how many pieces of each Data/Goods type are still needed to hit the goal, and roughly how many merits you'd earn if you filled the remaining goal with that category alone.

6

Share it

Use “Copy Task” to post the full breakdown to Discord, “Copy Inventory” to just post what you're currently carrying, or “Share Link” to hand the goal itself off to squadmates.
